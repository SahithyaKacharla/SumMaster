# 🧮 SumMaster (MathSprint)

A fun and interactive arithmetic game built using HTML, JavaScript, and Tailwind CSS. Players solve randomly generated addition problems within a limited time and try to achieve the highest score possible.

## 🚀 Overview

SumMaster is a browser-based math game designed to improve mental arithmetic skills through a fast-paced challenge. Players answer addition questions before the timer runs out while tracking their score in real time.

The project focuses on JavaScript fundamentals, DOM manipulation, timers, user interaction, and game logic implementation.

---

## ✨ Features

* ➕ Randomly Generated Addition Questions
* ⏱️ 30-Second Countdown Timer
* 🏆 Real-Time Score Tracking
* ✅ Instant Correct/Wrong Feedback
* 🔄 Restart Game Functionality
* 📱 Clean and Responsive User Interface
* 🎮 Interactive Gameplay Experience

## 🎮 How to Play

1. A random addition question appears.
2. Enter the correct answer.
3. Click **Check**.
4. Earn points for correct answers.
5. Continue solving problems before the timer reaches zero.
6. Try to achieve the highest score possible.
